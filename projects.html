C TWIXT

This was one of my CPro Assignments - a command line implementation of the game Twixt. I made it in C without using an external libraries. One of the main problems with the code was a lot of duplicate and unnecessary code which I didn't have to time to clean up. If I had to make it again, I would definitely address this. Also as this had to be entirely terminal based, I couldn't use any proper application libraries to actually recreate it 1:1 so I had to settle for an approximation in the terminals for the diagonal lines etc.

C UNPLUGGED

This was another one of my CPro Assignments. I had to essentially make a Spotify clone on the command line without the actually playing music part. I had to think a lot about this - for example, how I was going to store all the data etc - and learned to use data structures such as linked lists in an actual program for the first time. If I had to make it again, I would actually make it play music so it's kind of functional. Also, because I was restricted to pure C, I couldn't really make a proper UI interface for this.

THIS WEBSITE

Making this website was one of my toughest challenges. I initially underestimated it and started it a week before the deadline but it proved to be much more than I thought. I learned a lot about web design through the process and spent a lot of time trying to make it look right across all sizes and devices. If I had to do it again, I would add more cool features throughout the website like an actual navigation bar or something. The main technology tradeoff was using plain HTML, CSS and JS instead of external libraries which might have made my website look worse but I learned a lot by doing this.
